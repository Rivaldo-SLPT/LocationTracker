LocationTracker — Diseño de la base de datos

Cada teléfono guarda sus ubicaciones en local (SQLite) y las sube a AWS (DynamoDB). La página web las lee por deviceId.

Relación

Teléfono (deviceId) 1 ─── N Ubicaciones
  • Cada instalación de la app genera un deviceId propio (UUID); el S24 conserva s24-ultra-001.
  • En DynamoDB, todas las ubicaciones de un teléfono comparten la misma clave de partición.

Ciclo de un registro

  • El servicio guarda una fila cada 30 s con synced = 0.
  • Sin señal nueva: repite la última posición con stale = 1.
  • El SyncWorker la sube; con HTTP 2xx pasa a synced = 1. Sin internet espera y reintenta.
